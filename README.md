## Задание 1
**Пояснения к IT ландшафту as-is**
- Команда цифровой трансформации розничного бизнеса в AS IS не поддерживает бизнес возможности, перечисленные в описании задачи, поэтому для нее не отражены никакие IT системы
- Интернет банкинг и сайт в AS IS не участвуют ни в одной бизнес возможности, перечисленных в описании задачи, поэтому эти IT системы не отражены в IT ландшафте
